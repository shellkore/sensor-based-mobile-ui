# Web examples

See [magnetic-example.jsx](magnetic-example.jsx) for a React example of `MagneticUI`. Use it in a client component in Next.js. [scared-demo.html](scared-demo.html) illustrates `ScaredUI` behavior with simulated light readings; see the root README for React usage of both components. The [demo app](../../demos/README.md) offers interactive playgrounds using real sensors.
